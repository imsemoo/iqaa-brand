Scope: the Line screen of an organization's app (Sufra, sufra.iqaa.app/line): see the whole line, edit stations and steps, add branches and ways back, run a test job, publish a version. Mode: Operate.
Audience: the organization owner (Hala at Sufra), on a laptop most of the time; the same screen must work on a phone.
Task: change how jobs move, check the change with a test job that sends nothing, publish it. Running jobs keep their version.
Constraints: identity book binding (signature strokes: straight = runs, loop = a person does it, arch = waits for a person, dot = timed wait; violet only for a person; Atkinson + Fragment Mono; 600 ms beat). Branch types the build plan names: approval outcomes and conditions. Nothing presented as live.

## Direction contract

THESIS: the line as a metro map. The user chose it (2026-11-01) over a metro identity: the map is the product's working view, the signature stays the line's compact name, like a metro line's roundel beside its map. Refuses node-and-wire canvases (n8n, Zapier), kanban columns and flowchart diamonds.

MAP RULES (Beck, London 1933; Vignelli, New York 1972): even spacing whatever the duration; track runs horizontal, vertical or at 45° only, with rounded bends; every station is drawn as an interchange ring because a station is where work changes hands; a branch leaves at 45° below the line and rejoins it; a way back turns square, down, back and up, at half weight, so it never shares a 45° track with a branch leaving the same station. Phones turn the map vertical, the way a route view on a phone lists stops down the screen.

OWN-WORLD: white ground, ink track 6 px, station rings 18 px, lavender only for the selected station's band, violet only inside step strokes and the one primary button. The test job is grey and its trail is a dashed grey pen, the grammar's test state.

SIGNATURE INTERACTION: Run a test job. A grey job travels the map stop by stop at the tempo, takes each way back once and the branch its order qualifies for, and logs every step as "not sent: test".

MEMORABLE MOMENT: publishing: the pen writes the new version's signature in the page head.
